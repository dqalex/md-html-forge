# Archive

Historical documents kept for traceability. **Not maintained.** Links inside
these files may point to paths that no longer exist — that's intentional; the
files are frozen snapshots of the project at the time they served their purpose.

## What's in here

| Folder | Why it's archived |
|---|---|
| `migration/` | HTML → forge component migration is **done** (audit: 21/21 green). These were the operational docs for that effort. |
| `prompts/` | Task-dispatch prompts for agent workflows (F1–F7 + earlier sprints). All completed or obsolete. |
| `product/` | Early positioning / direction / roadmap docs. The decisions are now baked into the main [README](../../README.md) and code. |

## If you're new here

You probably want [`../engine/`](../engine/) (long-lived API reference) or the
top-level [`README.md`](../../README.md). This folder is only useful if you're
digging into project history, not learning how to use forge.
